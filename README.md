## 🎯 Getting Started

### Requirements
- Flutter 3.3.2 or higher
- Dart 3.8.0 or higher
- Android API 21+ / iOS 12.0+

### Installation
```bash
# Clone the repository
git clone https://github.com/yourusername/moinsen_physics.git

# Install dependencies
cd moinsen_physics
flutter pub get

# Run the game
flutter run
```

### Controls
- **Tap**: Interact with objects
- **Drag**: Create gravity fields (in Gravity Paint mode)
- **Buttons**: Activate special abilities
  - **REWIND**: Go back in time up to 5 seconds
  - **QUANTUM**: Toggle quantum superposition
  - **GRAVITY**: Paint custom gravity fields
  - **ENERGY**: Trigger energy bursts
  - **PORTAL**: Create linked portals
